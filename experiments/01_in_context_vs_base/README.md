# Experiment 1: in-context prior versus base

## Question

Can Qwen3-8B infer a fictional multiplicative power law from controlled numerical
observations, and does an incompatible law supplied in context bias that inference?

## Laws

The stated prior is

$$
L_A:\qquad \tau=3m^1r^2q^{-1}s^0.
$$

The conflicting evidence is generated by

$$
L_B:\qquad \tau=3m^1r^1q^{-2}s^0.
$$

The fictional variable names reduce direct lexical association with familiar named laws.
They do not remove the model's general mathematical knowledge about power laws.

## Why the feasibility gate comes first

A conflict experiment is uninterpretable if the base model cannot infer the target law
from evidence alone. The original random multivariable design was too dependent on
executing numerical log-linear regression. The final design therefore uses a baseline
row and two controlled interventions for each variable.

The replicated $L_A$ feasibility gate used:

- Qwen3-8B 4-bit through MLX;
- 20 independently varied datasets;
- five stochastic samples per dataset;
- thinking enabled;
- temperature 0.6;
- a 4,096-token generation limit.

Among 98 completed responses, 96 returned valid final JSON with the exact target law.
The two completed contract failures and two truncated traces also derived the correct
exponents. No parsed response proposed a scientifically wrong law.

## Matched $L_B$ comparison

The primary comparison used identical dataset seeds 2000 through 2009.

### No-prior arm

The model receives the fictional vocabulary, controlled measurements, hypothesis class,
and output schema, but no statement of either candidate law.

Nine responses returned valid exact $L_B$. The tenth derived exact $L_B$ but produced
an internally inconsistent abstention object.

### Guided in-context arm

The system prompt states $L_A$ and says that observations may confirm or contradict the
background law. All ten responses returned exact $L_B$, and none returned $L_A$.

### Bare in-context arm

The system prompt states $L_A$ but removes the explicit contradiction and override
guidance. Nine responses completed with exact $L_B$. The tenth trace derived exact
$L_B$, wrote the correct JSON inside its reasoning, and then reached the token limit
while continuing to verify the result. No trace returned $L_A$.

## Interpretation

The experiment supports a narrow null result:

> A law stated in context did not measurably bias Qwen3-8B against a clean, decisive,
> numerically inferable alternative law.

This does not show that in-context priors never affect inference. The evidence is
noise-free, each variable is directly intervened on, and the two laws disagree strongly.
Ambiguous or noisy evidence may behave differently.

It also does not test persistent learning. Information supplied in context is temporary
and explicitly visible to the model. Weight-encoded priors are addressed in a later
experimental block.

## Reproduction commands

Run these from the repository root after installing the `mac` optional dependency.

### Replicated feasibility gate

```bash
prior-evidence-gate \
  --condition confirming \
  --prior-arm none \
  --datasets 20 \
  --samples-per-dataset 5 \
  --start-seed 1729 \
  --max-tokens 4096 \
  --output-dir outputs/feasibility-replicated
```

### No-prior $L_B$ baseline

```bash
prior-evidence-gate \
  --condition conflicting \
  --prior-arm none \
  --datasets 10 \
  --samples-per-dataset 1 \
  --start-seed 2000 \
  --max-tokens 6144 \
  --output-dir outputs/no-prior-law-b
```

### Guided in-context $L_A$ prior

```bash
prior-evidence-gate \
  --condition conflicting \
  --prior-arm in_context \
  --datasets 10 \
  --samples-per-dataset 1 \
  --start-seed 2000 \
  --max-tokens 6144 \
  --output-dir outputs/in-context-guided
```

### Bare in-context $L_A$ prior

prior-evidence-gate \
